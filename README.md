# IMDb Plex Cloud Importer

Import personal ratings from an IMDb CSV into your online Plex account, including movies and shows that are not on your Plex server. A Plex server or Synology NAS is not required.

Unofficial, experimental command-line release (0.1.0). It uses Plex's online metadata API, which can change. It imports ratings only; it does not import watch history, download media, or continuously sync IMDb. Recommendation changes are not guaranteed.

## Install

Install Python 3.10 or newer. Download and extract this project, open a terminal in its folder, and run:

```sh
python -m pip install .
```

Use `python3` instead of `python` if that is how Python is installed on your computer. A virtual environment is recommended. The project uses PlexAPI for Plex sign-in; you never enter your Plex or NAS password into this tool.

## Import

Export **Your Ratings** from IMDb as a CSV. The unmatched CSV from [Ratings-To-Plex-Ratings](https://github.com/primetime43/Ratings-To-Plex-Ratings) is also supported.

`examples/example-ratings.csv` contains invented titles and identifiers to demonstrate the format. Use your own IMDb export for an actual import.

1. Create a preview, replacing the CSV path with your file:

   ```sh
   python -m imdb_plex_cloud plan /path/to/ratings.csv --state-dir ./private-state
   ```

   Authorize the tool on Plex's website using the temporary link displayed in your terminal. Keep this link private. Check that you approve the intended Plex account. The preview reads Plex data without changing ratings.

2. Open `private-state/plan.json` in a text editor. Review the matches, scores, excluded rows, and Plex titles. Do not edit this file. Only exact IMDb identifier matches with the correct media type are eligible; ambiguous or unverified results are skipped. If lookups failed, create a new preview in a new folder when connectivity recovers.

   ```sh
   python -m imdb_plex_cloud apply --state-dir ./private-state --dry-run
   ```

   This prints the number of eligible ratings without signing in or changing anything. It does not recheck online matches.

3. Apply the reviewed preview:

   ```sh
   python -m imdb_plex_cloud apply --state-dir ./private-state
   ```

   Type `IMPORT` when prompted and authorize Plex again. Existing personal scores can be replaced. The previous score is saved locally **before** each write, and the new score is read back to verify it. Equal scores are left unchanged.

Keep the whole state folder. If interrupted, repeat the same `apply` command to resume. Completed entries are skipped, and failed entries are retried. A run stops after three consecutive failures. Use a **new state folder** for a new CSV or a new import. Do not run multiple processes against the same state folder.

## Undo an import

```sh
python -m imdb_plex_cloud restore --state-dir ./private-state
```

Type `RESTORE` and sign in to the same account. This restores backed-up scores, including clearing a rating if none existed before. It skips a title if its current score differs from the imported score, preserving later edits. An edit that happens to have the identical score cannot be distinguished from the import. Failed restores can be retried with the same command. Backup and restore are best-effort; retain the files and review reported failures.

## Options and supported titles

- `--no-browser`: print the temporary Plex sign-in link without opening it, useful on a NAS or headless computer. Open it privately on another device. No incoming port needs to be exposed.
- `--rate 1`: lower the API request rate (default 2, maximum 4 requests per second). Temporary failures use limited retries.
- `apply --yes` / `restore --yes`: explicitly authorize writes without the typed confirmation. Plex sign-in is still required.
- Movies, TV movies, specials, shorts, videos, TV series, and miniseries are supported when Plex has a matching catalog entry. TV episodes and video games are excluded. Some IMDb titles may have no Plex match.
- Identical duplicate entries are collapsed. Conflicting duplicates are excluded. Ratings must be finite numbers between 1 and 10.
- Exit status `0` means success, `2` means an error, incomplete lookup/import, or restore conflict; `130` means interrupted. Inspect the preview and private reports for details.

## Privacy and publishing

Tokens stay in process memory and are not written into project state files. API tokens are sent in headers over HTTPS; authenticated API redirects are refused. PlexAPI handles the official Plex authorization flow. The printed authorization link is sensitive: do not paste it into issues, logs, or screenshots. Plex may retain the authorized device; review authorized devices in your account if you want to revoke access.

The CSV, plan, backups, checkpoints, and restore reports contain personal ratings and/or account identifiers. Never publish them. State directories and files use owner-only permissions on POSIX systems. On Windows, keep them in a private user folder and use the operating system's access controls.

The repository's `.gitignore` excludes common private files, but ignore rules do not remove files already tracked by Git. Publish only the source, documentation, tests, license, and synthetic example. Review Git's staged changes before committing. Never upload a working NAS container, personal CSV, state folder, browser screenshot, `.env`, or a ZIP of your runtime directory. See [SECURITY.md](SECURITY.md).

## Development and validation

```sh
python -m unittest discover -s tests -v
python -m imdb_plex_cloud --help
```

Tests use fake clients and HTTP responses: no account, network connection, or real ratings are needed. They cover CSV validation, matching, backups, resume, restore, and credential handling. This packaged release has not undergone a fresh end-to-end test against a real Plex account; the underlying online rating approach was exercised separately. Review the preview before applying to your account.
